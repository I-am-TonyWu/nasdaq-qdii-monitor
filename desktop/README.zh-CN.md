# 纳指观察 Windows 程序 v0.5.0

双击 **NasdaqQDII.exe**。首次启动会解压内置运行环境、创建桌面与开始菜单快捷方式，并在默认浏览器中打开观察网站。无需安装 Python 或 Node.js。支持 Windows 10/11 x64，需要系统自带的 .NET Framework 4.8。

## 日常使用

- 右下角托盘图标：双击打开网站，右键打开菜单。
- 菜单提供立即采集、更新基金、补采、数据库备份和设置。
- 关闭设置窗口后仍在托盘运行；“退出程序”会停止本程序启动的服务。
- 如果原项目服务已经运行，程序会连接原服务；退出时保留原服务。
- 设备需联网才能采集；已保存的历史数据可离线查看。系统代理会传给内置采集进程。

## 沿用当前项目

从项目的 `outputs/releases/NasdaqQDII-0.5.0` 中启动时，程序会识别上层项目目录，继续使用已有数据、配置和用户确认的渠道。原来的自动任务继续运行。本次打包不会替换正在运行的服务。

把 EXE 移到其他目录后再首次启动，如果此前没有保存数据目录，会创建独立的新数据目录。也可明确指定：

```powershell
.\NasdaqQDII.exe --home "D:\纳指观察数据"
```

新数据目录首次联网启动会进行采集。首次采集期间设置窗口显示进度；有快照后打开网站。源站暂不可用时会保留缺失状态，不生成虚构数据。

## 自动任务

右键托盘 → 设置与自动任务 → **自动任务** → **启用 / 修复自动任务**。使用当前 Windows 用户登录会话，不需要管理员权限。设备时区需为北京时间 UTC+8。

| 任务 | 北京时间 |
| --- | --- |
| 程序启动 | 登录 Windows |
| 全量采集 | 登录、06:30、06:45、12:30 |
| 未齐数据补采 | 07:15–17:15，每 30 分钟 |
| 早报冻结 / 预览 | 06:55 / 07:00 |
| 基金更新 | 09:10、14:30、20:30 |
| 数据库备份 | 07:10 |
| 周档 | 周六 12:30 |

同一数据目录的原同名任务会先备份 XML 再更新执行路径；正在运行的原服务任务保留。同名任务如果属于另一目录则拒绝覆盖。任务备份在数据目录的 `logs/task-backups`。早报仅生成本地预览，程序没有邮件发送按钮。

“登录 Windows 后自动启动程序”只控制托盘启动。如果已启用计划任务中的启动任务，取消此复选框不会删除计划任务。退出托盘也不会禁用采集计划任务。

## 远程访问（可选）

托盘 → 设置与自动任务 → **远程访问**。填入域名、账户 ID、区域 ID、Zero Trust 团队名称和允许登录的邮箱。

API Token 可以使用独立 Token，也可以勾选共用 codex-web 当前 Windows 账户加密保存的 Token。权限要求：

| 范围 | 权限 |
| --- | --- |
| 对应账户 | Cloudflare Tunnel / Edit |
| 对应账户 | Access: Apps and Policies / Edit |
| 对应域名区域 | DNS / Edit |
| 对应域名区域 | Zone / Read |

点击“检查 Token”只验证有效性和读取权限；点击“配置并启用”会逐项验证编辑权限。程序先创建并核对指定邮箱的 Access 保护，再设置独立隧道和 DNS，隧道也校验 Access JWT。失败不会启用连接；原资源 ID 会保存，可在解决权限后继续配置。不自动覆盖已有的其他 DNS/Access/隧道资源。

管理 API Token 与运行隧道 Token 是两种凭据。共用管理 Token 不代表共用隧道；退出或暂停本程序不会停止 codex-web。凭据使用 Windows 当前用户 DPAPI 加密保存在 `%LOCALAPPDATA%\NasdaqQDII\secrets`，不写进命令行、Git 或发布包。

此电脑需联网并保持托盘运行。勾选登录启动可随 Windows 登录恢复远程连接。关闭设置窗口保留连接；“暂停远程访问”停止连接但保留 DNS 与 Access。退出或意外结束托盘会停止自己的隧道。更改本机端口后，需重新“配置并启用”同步隧道入口。

本次发布的云端配置尚未启用；当前共用 Token 缺少 DNS 权限，按用户选择稍后补齐。本机已保留输入信息，公开安装包仍是通用空配置。公网邮箱登录、真实隧道恢复和其他设备访问尚未完成端到端验证。

## 文件位置与升级

| 内容 | 位置 |
| --- | --- |
| 稳定启动文件 | `%LOCALAPPDATA%\NasdaqQDII\app\NasdaqQDII.exe` |
| 按版本分开的运行文件 | `%LOCALAPPDATA%\NasdaqQDII\releases` |
| 托盘和服务日志 | `%LOCALAPPDATA%\NasdaqQDII\logs` |
| 新安装的数据目录 | `%LOCALAPPDATA%\NasdaqQDII\workspace` |
| 原项目数据 | 原项目目录内的 `data`，不会迁移或删除 |

退出托盘后双击新版本 EXE 即可升级。运行文件与数据分开，升级保留数据目录指针；旧启动文件另存为 `NasdaqQDII.exe.previous`。自动任务若指向旧版本运行目录，升级后从设置中修复任务。保留旧运行目录，直到确认任务已经更新。

“备份数据库”使用 SQLite 一致性备份，保存于 `data/backups`；它只包含数据库。迁移到其他电脑时，退出托盘并暂停原采集任务，再复制整个数据目录所对应的工作目录，包括 `data`、`config.local.json`（如有）和 `config/manual_channels.json`（如有）。个人配置与渠道确认不包含在通用安装包中。

程序只监听 `127.0.0.1`，网站接口只读，适用于本机个人使用。发布包没有附带行情历史、源站缓存、个人渠道确认、密钥或聊天资料。数据源原有使用限制仍适用。

## 故障处理

- 端口冲突：设置中更换端口并应用。不会关闭占用端口的其他程序。
- 服务错误：查看日志，然后点击“应用端口 / 重试”或托盘的“启动 / 重试服务”。
- 更新失败：先检查网络及系统代理；已有快照继续保留。
- 核验下载：使用同目录 `SHA256SUMS.txt` 的 SHA-256 摘要核对文件。EXE 未做代码签名。
